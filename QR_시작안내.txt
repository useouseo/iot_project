RestFlow v3 MariaDB + 주소 자동 QR

[실제 기기 2대 연결 및 휴대폰 QR 시험]
1. 압축을 풀고, PC의 MariaDB 서비스가 실행 중인지 확인합니다.
   Python 3.12 64-bit와 인터넷 연결이 필요합니다.
2. start_public.bat를 더블클릭합니다.
   첫 실행은 라이브러리와 공식 Cloudflare 도구를 다운로드합니다.
3. DB 설정이 없으면 DB 호스트/포트/계정/비밀번호를 입력합니다.
   이미 db_config.json을 설정했다면 그대로 사용합니다.
   기본값은 localhost:3306, 실사용 DB restflow, 가상 시연 DB restflow_demo입니다.
4. 관리자 비밀번호가 초기값이면 새 비밀번호(8~128자)를 정합니다.
   입력 중 글자가 안 보이는 것이 정상입니다. 기존에 바꿨다면 그 비밀번호를 사용합니다.
5. 자동으로 열린 관리자 화면에서 로그인하고 QR 생성 버튼만 누릅니다.
   IP 조회나 방문객 주소 입력이 필요 없습니다.
6. QR을 PNG/SVG로 저장하거나 휴대폰으로 스캔합니다. LTE/5G에서도 접속할 수 있습니다.

[중요: 이번 버전의 public 기본 모드]
start_public.bat는 실제 센서 모드로 database(기본 restflow)를 사용합니다.
기존 public 데모 버전과 다릅니다. 가상 데이터가 실제 센서 화면에 섞이지 않습니다.
가상 데이터로만 QR 화면을 시험하려면 start_public_demo.bat를 더블클릭합니다.
또는 명령 프롬프트에서 start_public.bat --demo를 실행합니다.
이때는 demo_database(기본 restflow_demo)를 사용합니다.
두 DB의 시설/장치/비밀번호는 각각 독립적으로 보존됩니다.

[기기 연결]
실제 센서 모드에서 각 화장실에 서로 다른 장치 ID를 등록하고 토큰을 발급합니다.
기기 2대에는 각각 자기 장치 ID와 토큰을 넣습니다. 같은 ID/토큰을 공유하지 마세요.
실행 창에 표시되는 공개 HTTPS 주소를 firmware/include/secrets.h의 API_BASE에 넣습니다.
ROOT_CA는 해당 HTTPS 서버 인증서를 검증할 수 있는 루트 CA를 사용해야 합니다.
인증서 확인을 끄는 setInsecure()는 사용하지 않습니다.
실제 Wi-Fi 정보와 토큰, CA 설정 후 빌드/업로드가 별도로 필요합니다.
기존 펌웨어는 HTTPS 방식을 사용하며, 이번 변경으로 기기 설정까지 자동화되지는 않습니다.
공개 주소가 바뀌면 QR뿐 아니라 기기의 API_BASE도 변경하고 다시 업로드해야 합니다.
따라서 센서 시연을 준비한 뒤에는 PC와 연결을 계속 유지하세요.
서버 설정만으로 실제 기기가 자동 등록되거나 연결되지는 않습니다.

[연결 유지]
PC와 MariaDB 서비스, 검은 실행 창을 계속 켜두세요. 종료는 Ctrl+C입니다.
PC 절전/인터넷 끊김/Cloudflare 장애가 있으면 접속되지 않을 수 있습니다.
다시 실행하면 임시 공개 주소가 바뀌므로 QR도 다시 생성합니다.
MariaDB 데이터는 DB를 삭제하지 않는 한 서버 실행 종료만으로 지워지지 않습니다.
Quick Tunnel은 시험용으로, 고정 주소와 가용성을 보장하지 않습니다.

[문제 해결]
- DB 연결 실패: MariaDB 서비스 실행과 db_config.json의 계정/비밀번호를 확인하세요.
- 설정 다시 입력: .venv\Scripts\python.exe setup_mariadb.py
- 8000 포트 사용 중: 이전 서버를 Ctrl+C로 종료하세요.
  또는 명령 프롬프트에서 start_public.bat --port 8001을 실행하세요.
- mariadb_config/패키지 설치 오류: Python 3.12 64-bit를 사용하고,
  필요한 경우 공식 MariaDB Connector/C를 설치하세요.
- 공개 주소 연결 실패: 인터넷, 회사/학교 네트워크 차단을 확인하세요.
  기존 사용자 폴더의 .cloudflared/config.yml이 Quick Tunnel과 충돌할 수도 있습니다.
- QR은 나오는데 LTE에서 안 열림: 창이 실행 중인지 확인하고 몇 초 후 다시 시도하세요.
- db_config.json에는 DB 비밀번호가 들어갈 수 있습니다. 공유/커밋하지 마세요.

[고정 서버를 구매한 뒤]
MariaDB와 Python을 서버에 설치한 뒤 DB 계정 및 백업을 구성합니다.
HTTPS 프록시 및 고정 주소를 설정하고 PUBLIC_URL에 그 공개 주소를 지정합니다.
server.py는 --demo 없이 실행합니다. QR 버튼은 PUBLIC_URL을 자동 사용합니다.
예: PUBLIC_URL=https://본인도메인 (서버 환경변수)
PC MariaDB 데이터가 서버로 자동 이전되지는 않으므로 필요하면 별도 백업/복원합니다.
이번 수정은 PC 임시 공개 실행 준비이며, 유료 서버 구매/배포는 하지 않았습니다.
