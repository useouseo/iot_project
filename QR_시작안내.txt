관리자 주소 입력 없이 QR 만들기

[지금 PC에서 시험하기]
1. 압축을 풀고 start_public.bat를 더블클릭합니다.
   Python 3.12 이상과 인터넷 연결이 필요합니다.
   첫 실행은 Python 라이브러리와 공식 Cloudflare 연결 도구를 내려받습니다.
2. 관리자 비밀번호가 초기값이면 새 비밀번호를 설정합니다.
   비밀번호 입력 중에는 글자가 보이지 않습니다. 기존에 변경했다면 그 비밀번호를 씁니다.
3. 자동으로 열린 관리자 화면에서 로그인하고 'QR 생성'만 누릅니다.
   IP 조회나 주소 입력이 필요 없습니다.
4. PNG/SVG로 저장하거나 휴대폰으로 스캔합니다. LTE/5G에서도 접속 가능합니다.

PC와 검은 실행 창을 켜두어야 합니다. 종료는 Ctrl+C입니다.
임시 공개 주소는 다시 실행할 때 바뀝니다. 다시 실행하면 QR도 다시 생성하세요.
이전에 인쇄한 QR을 계속 쓰려면 아래 고정 주소 배포가 필요합니다.
Cloudflare Quick Tunnel은 시험용이며 서비스 보장이나 고정 주소를 제공하지 않습니다.
회사/학교 네트워크 제한, 인터넷 장애, Cloudflare 장애 시 연결되지 않을 수 있습니다.
실제 Windows PC에서 휴대폰 스캔까지 확인 후 사용하세요.
기존 start_demo.bat는 PC 로컬 데모용으로 그대로 사용할 수 있습니다.
이 공개 실행은 기존 .runtime/demo.sqlite3의 설정과 데이터를 사용하며 데모 모드입니다.
실제 센서 운영은 --demo 없이 실행하는 고정 배포를 사용하세요.

[고정 공개 주소로 운영하기 — Render 예시]
render.yaml은 실제 Python 서버와 SQLite 데이터를 보존하는 배포 설정입니다.
Render 계정과 Git 저장소가 필요하며, 영구 디스크를 사용하는 유료 서비스입니다.
이 압축 파일만으로 배포되거나 결제되지는 않습니다.
1. 프로젝트 소스를 비공개 GitHub 저장소에 올립니다.
   .runtime, .venv, 실제 장치 secrets.h는 올리지 않습니다.
2. Render에서 New > Blueprint로 저장소를 연결합니다.
3. INITIAL_ADMIN_PASSWORD에 직접 정한 8자 이상 비밀번호를 지정합니다.
   요금제/비용을 확인한 뒤 생성합니다.
4. Render가 제공하는 https://...onrender.com/admin으로 접속합니다.
5. 로그인 후 QR 생성만 누릅니다. RENDER_EXTERNAL_URL을 자동 사용합니다.
   공개 주소를 유지하면 재시작 후에도 기존 QR을 쓸 수 있습니다.
   기존 PC DB가 자동 이전되지는 않으며 시설/장치 설정은 별도로 옮겨야 합니다.

[개발 변경]
POST /api/qr: 관리자 인증 후 서버의 공개 주소를 우선 사용해 SVG와 URL을 함께 반환합니다.
공개 주소가 없으면 브라우저 접속 주소를 사용하며 로컬/사설 IP는 외부용 QR에서 차단합니다.
PUBLIC_URL 또는 Render의 RENDER_EXTERNAL_URL은 서버 운영자가 설정합니다.
기존 수동 주소 API는 호환성을 위해 남겨두었지만 새 QR 버튼에는 사용하지 않습니다.
