## 재현

MariaDB 서비스와 테스트 DB 생성·삭제 권한을 준비합니다. `db_config.json` 또는 DB 환경변수를 설정한 뒤 프로젝트 루트에서 실행합니다.

```text
python -m unittest discover -s tests -v
node --check web/app.js
```

테스트는 설정한 실사용/시연 DB와 다른 `_test`, `_launcher_test` DB를 생성·삭제합니다. 기존 실사용 데이터에 대해 실행하지 않습니다. DB 비밀번호·장치 토큰·Wi-Fi 비밀번호는 로그나 Git에 올리지 않습니다.

C++ 컴파일러가 있는 개발 환경에서는 다음을 실행합니다.

```sh
g++ -std=c++11 -Wall -Wextra -pedantic tests/direction_test.cpp -o /tmp/restflow-direction
/tmp/restflow-direction
```
