# 야외 지도와 도보 길찾기

방문객은 공통 QR로 HTTPS 페이지에 접속하고 위치 권한을 허용합니다. TMAP 지도에서 화장실을 선택하면 보행자 경로를 표시합니다. 현재 위치 오차 원, 경로 거리 및 예상 분 단위를 표시합니다. 음성 안내와 자동 재탐색은 포함하지 않습니다. 위치는 서버 DB에 저장하지 않으며 길찾기 요청 시 TMAP으로 출발 좌표를 전달합니다.

## 설정

TMAP Open API 계정에서 JavaScript 지도 SDK와 보행자 경로 API의 사용 권한, 허용 도메인, 현재 요금 및 호출량을 확인하고 발급받은 키를 설정합니다.

- `RESTFLOW_TMAP_MAP_KEY`: 브라우저 지도용 키. 브라우저에 공개되므로 허용 도메인을 제한하세요.
- `RESTFLOW_TMAP_ROUTE_KEY`: 서버 보행자 API 키. 브라우저에는 전달하지 않습니다. 서버 환경변수 또는 `RESTFLOW_TMAP_ROUTE_KEY_FILE`로 지정합니다.

키를 코드나 GitHub에 저장하지 마세요. 키가 없으면 지도 설정 안내를 표시하며 혼잡도 목록은 계속 동작합니다.

Windows CMD에서 실행할 경우 같은 창에서 환경변수를 설정한 후 기존 BAT를 실행합니다. 아래 값은 자리표시자입니다.

```bat
set "RESTFLOW_TMAP_MAP_KEY=발급받은_지도용_키"
set "RESTFLOW_TMAP_ROUTE_KEY=발급받은_보행자_API_키"
start_public_demo.bat
```

Docker 배포는 `deploy/.env`에 두 변수를 추가한 후 앱을 다시 생성합니다. 기존 configure.py를 다시 실행하면 .env를 다시 쓰므로 TMAP 값을 보존하세요. 운영 환경에는 API 제공자 측 일일 한도도 설정하세요. 앱은 전체 서버 기준 초당 1회 호출 제한과 동시 호출 제한을 적용합니다.

## 화장실 등록

1. 관리자 로그인 → 시설 관리에서 화장실을 추가하거나 선택합니다.
2. 지도를 이동·확대해 선택된 A/B/C 마커를 **실제 화장실 입구로 드래그**합니다. 위치가 없는 새 시설은 지도 중앙에 반투명 마커가 표시됩니다. 지도 클릭 및 위도·경도 직접 입력도 가능합니다.
3. 지도 아래 **위치 저장**을 누릅니다. 저장 전에는 **위치 되돌리기**로 취소할 수 있고, 5초 갱신에도 임시 위치가 유지됩니다. 이름·칸 수 저장과 별도입니다.
4. 휴대폰으로 방문객 화면에 접속해 현재 위치와 경로를 확인합니다.

기존 이미지의 X/Y는 그대로 보존합니다. 신규 latitude/longitude 컬럼은 시작 시 자동 추가되며 기존 시설의 실제 좌표는 비어 있습니다. 기존 배치도 위치를 실제 좌표로 자동 변환하지 않습니다. 좌표가 없는 화장실은 목록에만 표시하며 길찾기는 비활성화됩니다. 지도 기본 중심은 서울시청이며, 실제 화장실을 등록하면 그 위치로 이동합니다. 허위 시연 좌표를 실사용 시설에 넣지 않습니다.

## 현장 확인

- HTTPS, 위치 권한 허용/거절, 위치 재시도, 휴대폰 화면 크기 확인
- 지도 SDK 인증과 보행자 API 인증, 거리·시간·경로 좌표 확인
- API 키 없는 경우/한도 초과/네트워크 실패 안내 확인
- 실제 입구까지 걸어가며 경로 확인: 행사장 임시 통로와 출입 통제는 TMAP에 없을 수 있습니다.
- 내 위치 확인 버튼은 매번 캐시 없이 새 위치를 요청합니다. 60초 이상 지난 위치는 길찾기 전에 자동으로 다시 확인합니다. 오차가 100m를 넘거나 새 위치 조회에 실패해 마지막 위치를 쓸 때에는 출발 위치를 확인하고 계속할지 묻습니다. 위치 권한을 거부하면 길찾기는 진행하지 않습니다.
- 목적지를 바꾸면 이전 경로를 지웁니다. 이동 중 자동 경로 재계산은 하지 않으므로 버튼으로 다시 조회합니다.

TMAP 키가 없는 개발 환경의 자동 검사는 대체 SDK/응답으로 화면 흐름을 확인합니다. 실제 지도 타일, 계정 이용 조건, 실기기 GPS 및 현장 경로는 유효한 키와 현장 검증이 필요합니다.

마커는 기존 배치도처럼 A/B/C와 혼잡도를 표시하는 핀 모양입니다. 실제 이름은 목록과 마커 설명에 표시합니다. 방문객은 마커를 이동할 수 없습니다.

개발용 드래그 회귀 확인: `python tools/outdoor_smoke.py` (Playwright와 Chromium 필요, 대체 TMAP SDK 사용).

위치 재조회 회귀 확인: `python tools/location_smoke.py` (대체 위치 API/지도 SDK로 재시도·정확도·시간 초과·권한 거절 확인).
