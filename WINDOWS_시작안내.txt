QR 자동 연결 실행 안내

1. ZIP을 압축 해제한 폴더에서 start_public.bat를 더블클릭하세요.
2. Python 3.12 이상과 인터넷 연결이 필요합니다.
3. 첫 실행은 필요한 라이브러리와 Cloudflare 연결 도구를 다운로드합니다.
4. 초기 관리자 비밀번호를 사용 중이면 8자 이상 새 비밀번호를 설정합니다.
   비밀번호 입력 중 글자가 표시되지 않는 것이 정상입니다.
5. 자동으로 열린 관리자 화면에 로그인한 뒤 QR 생성 버튼을 누릅니다.
   IP 확인이나 주소 입력이 필요 없습니다.
6. PNG/SVG 다운로드 또는 휴대폰 카메라 스캔으로 사용합니다.

PC와 실행 창을 켜두어야 합니다. 종료는 Ctrl+C입니다.
다시 실행하면 공개 주소가 바뀝니다. QR도 다시 생성하세요.
기존 설정을 유지하려면 기존 .runtime 폴더를 보존하세요.
start_demo.bat는 기존 PC 로컬 데모 실행용입니다.
고정 주소 운영 방법과 주의 사항은 QR_시작안내.txt를 확인하세요.
