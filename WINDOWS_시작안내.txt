RestFlow Windows 실행 안내

1. ZIP을 먼저 압축 해제하세요. ZIP 내부에서 바로 실행하지 마세요.
2. Python 3.12 이상을 설치하세요. 설치할 때 Add python.exe to PATH를 선택하세요.
3. iot_project 폴더 안의 start_demo.bat를 더블클릭하세요.
   처음 실행하면 가상환경을 만들고 QR 라이브러리를 설치하므로 인터넷이 필요합니다.
4. 서버가 시작되면 브라우저에서 http://localhost:8000 으로 접속하세요.
5. 관리자는 PC 또는 휴대폰에서 http://localhost:8000/admin 으로 접속합니다.
   최초 비밀번호는 1234이며 로그인 후 관리자 비밀번호 변경에서 바꿀 수 있습니다.
   토큰 파일을 열 필요가 없습니다. 방문객 화면에는 관리자 메뉴가 없습니다.
   휴대폰에서는 localhost 대신 접속 가능한 PC 내부 IP 또는 공개 주소 뒤에 /admin을 붙이세요.
6. 실행 중 명령창을 열어 두세요. Ctrl+C로 서버를 종료합니다.

명령 프롬프트에서 직접 실행하려면 압축을 푼 실제 폴더로 이동하세요.
예시:
cd /d "C:\Users\이서우\iot_project"
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python server.py --demo

실제 저장 위치가 다르면 첫 줄의 경로도 바꾸세요.
/workspace/iot_project는 클라우드 전용 경로입니다.

시연 모드의 통행량은 가상 데이터입니다. 가상 장치는 2분 후 오프라인으로 바뀔 수 있습니다.
관리자 화면의 시연 통행 데이터 추가 버튼을 누르면 새 데이터를 생성합니다.
실제 센서 모드는 --demo 없이 실행하며, 별도 장치 등록과 센서 설정이 필요합니다.

ESP32 전체 컴파일은 개발 클라우드의 PlatformIO 네트워크 차단으로 검증하지 못했습니다.
실물 센서 정확도와 배터리 지속시간도 미검증입니다.
상세 설계·부품·시험 문서는 docs 폴더를 확인하세요.

이 ZIP에는 소스·문서·화면 캡처와 펌웨어 예제만 포함합니다.
개인 토큰·Wi-Fi 비밀번호·실행 DB·Git 이력·가상환경은 포함하지 않습니다.

지도 위치: 관리자로 로그인해 지도 마커를 드래그하고 지도 아래 ‘위치 저장’을 누르세요.
QR 저장: 관리자 화면의 ‘방문객 QR’에 접속 주소를 입력하고 QR을 생성한 뒤 PNG/SVG 다운로드를 누르세요.
QR은 서버 폴더에 자동 저장되지 않으며 브라우저의 다운로드 위치에 저장됩니다.
localhost 주소는 현재 PC에서만 열립니다. 휴대폰용으로는 실제 접속 가능한 내부 IP 또는 공개 서버 주소가 필요합니다.
업데이트는 서버를 Ctrl+C로 종료한 뒤 파일을 덮어쓰고 start_demo.bat를 다시 실행하세요.
기존 .runtime 폴더를 유지하면 변경한 비밀번호와 저장된 설정이 유지됩니다. 브라우저 새로고침은 Ctrl+F5입니다.

화장실 수는 고정이 아닙니다. 관리자 화면에서 이름·칸 수를 입력해 추가하고, 선택한 화장실 삭제로 개수를 줄일 수 있습니다.
