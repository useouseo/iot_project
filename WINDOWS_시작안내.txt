MariaDB + QR 자동 연결 실행

1. Python 3.12 64-bit 및 MariaDB Server가 설치되어 있어야 합니다.
2. MariaDB 서비스를 실행합니다.
3. start_public.bat를 더블클릭합니다 (실제 센서 모드).
4. 첫 실행이면 MariaDB 계정 정보를 입력하고 관리자 비밀번호를 정합니다.
5. 열린 관리자 화면에 로그인하고 QR 생성 버튼을 누릅니다.
6. 휴대폰에서 LTE/5G로 QR 접속을 확인합니다.

가상 데이터 시연은 start_public_demo.bat를 사용하세요.
기존 설정 보존: db_config.json을 유지하고 MariaDB 데이터베이스를 삭제하지 마세요.
실행 종료: 검은 창에서 Ctrl+C. 다시 실행하면 새 QR이 필요합니다.
실제 기기는 새 공개 API_BASE, 장치 토큰, HTTPS 루트 인증서를 별도로 설정해야 합니다.
자세한 절차/문제 해결은 QR_시작안내.txt를 확인하세요.
